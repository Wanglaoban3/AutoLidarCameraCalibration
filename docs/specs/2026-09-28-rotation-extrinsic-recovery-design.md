# 跨模态旋转外参恢复级联 — 设计文档

- 日期：2026-09-28
- 状态：待评审
- 范围：`auto-extrinsics-adjusting` 仓库；nuScenes mini 开发 + 自有设备数据泛化（后期）

## 1. 背景与目标

仓库现有两条**粗修**管线（详见 `extrinsic_recovery/README.md`）：相机竖线 VP 法
（±2° pitch/roll 噪声 → 残差 0.507°）、LiDAR 地面格 + 立面弱约束法（→ 0.364°）。
两者都以重力为锚、只修 pitch/roll，且相互独立。

未覆盖的缺口：

1. **精度平台**：0.36–0.51° 距离量产规格（<0.1°、重投影几 px）差 5–10 倍；重力锚点
   只压公共分量，压不掉相机-LiDAR **相对**旋转分量。
2. **yaw 缺失**：现管线明确假设 yaw 由 IMU 提供。
3. **无跨模态细修级**：相机-相机极线精炼（`bev_opt_epipolar.py`，3.68px→0.44px）
   不能跨模态复用——LiDAR 与图像之间没有极线几何。
4. **评测协议缺失**：单 seed、单相机、单日志，无法支撑开源叙事。

**目标**：以现有粗修为前置级联，新增跨模态细修，把**旋转外参**（pitch/roll/yaw）
恢复到 <0.15°（好场景 <0.1°）、重投影 <3 px；并交付 Monte-Carlo 评测协议与门控，
使本仓库成为"带协议的级联恢复"开源项目，而非单个算法。

**应用场景**：出厂标定后安装旋转漂移（振动/碰撞/温差）的自动恢复。平移信任出厂
标定，不恢复。车载化是远期目标（Orin），本项目先做离线方法与协议。

## 2. 问题定义

- 噪声注入：`R_noisy = Cn @ R_gt`，`Cn = Rz(ψ)·Ry(θ)·Rx(φ)`。**注入维度扩展到
  yaw**（现仅 pitch/roll）。幅度网格 {0.5, 1, 2, 3}°，每格 10 seeds。平移保持 GT。
- 优化变量：`R_ec`（相机←ego）、`R_le`（LiDAR←ego），各 3 自由度，共 6 参数。
- 投影链（**逐 sweep 直接投影，不做点云地图积攒**）：
  `p_c = R_ecᵀ · [ R_ge(s) · (R_le · p_l + t_le) + (t_eg(s) − t_ec) ]`
  其中 `R_ec/R_le` 为传感器在 ego 系的旋转（与现有代码 `R_noisy.T @ g_target`
  的约定一致，ego→传感器方向取转置），ego 姿态与平移项均为已知量。地图积攒方案被否决：先修 LiDAR 再
  积攒地图修相机，0.36° 残差会以 6–7 px 的地图翘曲污染相机细修；联合优化下同一批
  图像边缘同时约束两个旋转，且重力粗修已打断两旋转绕重力轴的相关性，问题良构。
- 指标：修正量与注入量的测地距离（沿用现有口径，规避欧拉角奇异性）、安装系逐
  DoF 分解（roll/pitch/yaw）、LiDAR 边缘点重投影 px RMSE、收敛率、门控 ROC。

## 4. 细修方法 A：两阶段证据的深度-边缘对齐

### 4.1 证据（两阶段）

- **粗相位**（宽收敛域，~1°）：投影深度边缘点对图像边缘**距离变换**（soft DT，
  高斯模糊 σ 退火：大 σ 起步逐步收缩）做鲁棒 chamfer。
- **精相位**（亚像素，消除 DT 整像素量化偏差）：对每个投影深度边采样点，沿其
  法向在图像梯度幅值上 ±4 px 窗口搜索峰值，二次插值亚像素定位，TEED 概率图做
  验证门（≥0.2），残差 = 带符号法向偏移（连续值）。
  这是 `camera_vp_calib.subpixel_refine` 已验证模式（梯度定位 + TEED 门控）在
  跨模态场景的推广，直接回应用户"TEED 边缘不够精准"的关切：TEED 只负责选择
  结构，定位精度由图像梯度保证。

### 4.2 深度边缘提取

投影后图像空间 range 不连续检测（行/列差分，自适应阈值），输出边缘采样点及其
2D 法向。

### 4.3 掩膜（抑制系统性偏差）

- nuScenes 标注框剔除动态物体（车/行人）产生的边缘；
- 深度边只在有图像边支撑处参与（"墙面纹理边有图像边没深度边"的反向问题靠
  法向搜索窗自然截断）；
- FOV 与有效深度范围裁剪。

### 4.4 优化

- Gauss-Newton + Huber，多分辨率由 4.1 的 σ 退火承担；
- 初值 = 粗修结果；联合 6 参数；(可选开关) 弱重力先验正则稳定病态场景。

### 4.5 门控与聚合

- Hessian (JᵀJ) 逐 DoF 特征分解 → 可观测性门控：信息不足的自由度（如空旷场景
  yaw）输出不确定度并标记，不硬解；
- 逐帧修正量 → 中位数一致性筛选（复用粗修的 2° 门）→ 测量信息量逆方差四元数
  平均（复用粗修模式）。

### 4.6 证据族后验记录（2026-09-29，全部实测）

按"拉力探针"（基准位姿对每个自由度 ±0.1–0.5° 扰动，看池化代价是否向真值
下探）逐一证伪，七族证据无一从 ~0.5° 初值产生可发布的拉力；每族死因不同，
全部记录避免复发：

1. **soft-DT chamfer（σ 退火）**：稀疏采样下 DT 锥被 argmax 采样打碎，无盆地。
2. **冻结关联 ICP**：关联池过期/塌缩，拉力方向错误（0.36→1.0°）。
3. **外循环重提取 ICP**：证据与位姿共动，自证收敛。
4. **深度边采样 DT**：前景侧点才贴光度边（背景侧 ~17px）；不过滤则
   junk 梯度（冠层/纹理跳变）主导，huber 代价下降而中位数恶化；
   用图像邻近度过滤则**盆地消失**（任何位姿都贴着某条边）。
5. **地面-立面接触区间包含**：零信号，且提取随位姿共动。
6. **接触线 + 脊线关联**：提取极好（GT 中位 1.7px），但可重定位关联对
   相干滑移全盲——GT 零噪声检查漂移 0→0.90°，门控不可见。已降级实验。
7. **标记 rim-DT（参考仓库配方）**：单前相机 in-frame 仅 5%（漆面在侧向
   4–8 m，垂直 FOV 只吃 4.3–8 m 地面楔）；扩到 6 环视（in-frame 11–22%）
   后拉力探针仍平（GT 处 DT 中位 ~9px，对齐噪声把 ±0.5° 盆地埋死），
   18-DoF 逐相机扰动的 V 形曲率谷底偏离真值 0.1–0.3°（BEV rim 粗厚的
   系统偏差），fresh 1° 全漂移场景顶边界被门控拒绝。**该配方只能当
   ≤0.2° 的抛光，与参考仓库自身定位一致。**
8. **MI/NID（Pandey 2011 / Taylor-Nieto 2016，即基线 C）**：等频分箱 +
   15 万样本后 MI 仅 0.04 nats，曲面单调无峰（占用格偏差随错位增长，
   argmax 全部顶盒边）。在此数据量/传感器组合下不可用。

跨族教训：证据必须在**无图像**条件下物理可选；越界点用常数 barrier 兜底
（丢弃会被优化器赶出画面）；关联一旦可重定位，任何由重锁定目标算出的门控
都测不到相干滑移——GT 零噪声检查是唯一可靠的哨兵。

### 4.7 状态参数化修正（2026-09-29，用户澄清后）

实际漂移是 **6 相机 + 激光雷达全部 7 个传感器各自独立漂移**，不存在"干净
观察者"。修正：

- 状态 = 6 个相机各自的旋转增量（18 DoF，序 = CAM_CHANNELS），**激光雷达
  旋转钉为刚体锚**：其绝对误差由粗修/验证阶段负责，且在 lidar→相机投影中
  天然抵消；公共模态分量由 0.08/dim 初始化先验（"漂移是小量"）吸收。
- 18-DoF 分解本身恢复信号：逐相机误差对**自己的**证据是相干位移（探针
  V 形），而 6-DoF 公共扰动让前后相机证据反向相消、合并代价平坦。
- fresh 模式对 7 传感器各抽独立噪声；v1.0-mini 的 10 个 clip 按 **scene**
  枚举（8 个日志，n015-11-21 一个日志含 3 个场景）。
- 活跃候选 = 已发表方法移植（并行）：Levinson & Thrun 2012 深度边互相关、
  GRIL-Calib 2024 强度边 vs 图像边 DT、TLC-Calib 线匹配；配方机制
  （barrier/先验/holdout 门/边界规则）沿用参考仓库纪律。

### 4.8 并行移植与原样复现结论（2026-09-29 决定性轮）

六路并行（3 个论文移植 agent + 文献排查 agent + 参考仓库原样复现 +
18-DoF 多相机扩展），全部收敛到同一个物理根因：

- **统一的根因（HDL-32E 角间隔量化）**：光束角间隔 1.33° ≈ 光束发散角
  （1.29 mrad）的 18 倍。深度边缘点被 1.33° 角间隔空间量化（15 m 处
  ~18 px），任何"点-边对齐"目标都有 ≥20 px 的不可约错位本底，比 ±1°
  内的位姿信号（5-17 px）大。实测：GT 处 38.9%/39.7% 的边缘点在图像强
  边 10 px 内（0.5° 偏移无区分度）；MFCalib 膨胀修正走廊仅 ~6.5 px，
  两个量级不够；V 形曲线 0/12。
- **各线结果**（全部有数据，见 outputs/reports/）：
  - GRIL-24 移植：87.6% in-frame 但对应关系缺失，门控拒绝（GT 稳定）。
  - TLC 线匹配：线对线 0.4 组/帧饥饿；点到线回退有 ~5 px 系统差
    （LSD 不发墙基线），GT 门控拒绝。
  - L&T-2012 互相关：指标在真值处即偏好错误位姿（场景纹理偏差在
    train/holdout 共享，单相机逐场景门控原理性失效）。
  - MFCalib 正式版（膨胀偏置）：证伪测试 NO-GO（上条根因）。
  - MI/NID、标记-DT（1 相机与 6 相机）、深度边 DT 等 8 族自研证据：
    同根因，全部无盆地或有偏。
  - 参考仓库原样：MFCalib 简化版 0 阶段接受（±0.3° 也不行）；
    teed_stacked_refinement 在自己基准上 publish=false。
- **参考级联 10 场景表（它自己的基准配置，含手眼粗修 + TEED polish）**：
  最终误差 6/10 ≤0.78°（中位 0.78°），8/10 ≤1.6°，2/10 yaw 失败
  （15.2°/7.5°，粗修窗口激励不足）。结构：**roll/pitch 靠地面法向
  重力锚**（polish 的 gravity_constrain，从 8-15° 的粗修错误也能拉回
  ≤1°），**yaw 靠 LiDAR ICP 运动手眼**（激励不足的窗口失败），
  TEED 标记只做保守抛光 + 发布门。
- **漂移方向镜像实验（lidar 正确、相机污染）**：MFCalib 镜像注入
  0 阶段接受；18-DoF 标记-DT holdout 中位改善但盒边界命中被拒。
  漂移方向不改变结论——瓶颈在证据通道，不在参数化。
- **结论（spec 修订）**：在此数据上，跨模态细化的可达精度边界是
  ~0.3-0.8°（重力锚 + LiDAR 运动学 + 保守光度抛光）；"<0.15° 纯图像
  细修"需要 64 线级稠密点云或视频率图像，超出 mini 数据的物理极限。
  M2 协议以此边界为基线；若要突破，需要自有数据满足：≥64 线或
  高密度固态雷达、≥10 Hz 图像、含明显立面/杆状结构。

## 5. 验证 B 与基线 C

- **B 验证器**：细修后把 LiDAR 检出的立面平面/地面格投影回图像，与建筑竖线/
  地面掩膜计算贴合度，输出逐帧一致性分数 → 聚合门控输入 + README 可视化图。
- **C 基线**：NID（投影距离图 ↔ 图像强度互信息，多分辨率粗到细），一次性实现
  进协议，作为经典方法对照。

## 6. 评测协议

- 场景划分：mini 10 场景 → **3 tune / 7 protocol，不相交**，固定列表写入配置
  （沿用 OneVL-Q 的划分纪律）。
- 网格：噪声幅度 {0.5, 1, 2, 3}° × 10 seeds（含 yaw），protocol 场景上运行。
- 每格报告：逐传感器测地误差（before/after）、逐 DoF 分解、重投影 px、**收敛率**
  （<0.1° 占比）、门控 ROC（错误结果被拦截 vs 溜入）。
- **级联贡献分解表**：不恢复 → 仅粗修 → 粗修+细修(A) → +NID 对照，一张表讲清
  每级贡献。
- 输出：收敛曲线、逐场景热力表、失败案例分析（README 直接可用）。

## 9. 风险与对策

- 深度边 ↔ 图像边系统偏差 → 支撑掩膜 + B 验证 + 重投影 px 指标兜底；
- mini 场景多样性有限 → seeds 维度统计功效 + 后续自有数据；
- 联合 6 参数病态 → 重力粗修打断相关性 + 可选弱先验 + 逐 DoF 门控；
- TEED 边缘定位精度 → 两阶段证据，精相位由图像梯度亚像素定位保证（§4.1）。

## 附：从现有工作继承的关键教训

欧拉角对比在安装奇异性附近失真（指标用测地距离）；前视竖线 VP 在无穷远
（方向空间特征向量法）；立面法向自带 ~1° 真实倾斜（弱权重）；ego 姿态逐帧
变化必须逐帧补偿；BEV 地面对齐做优化目标会出假解（只做验证）；CAN-IMU 加速度
计被行驶动力学污染 ~5°（只做交叉诊断）。
